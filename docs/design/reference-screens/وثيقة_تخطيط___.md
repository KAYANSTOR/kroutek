# وثيقة تخطيط تطبيق "كيان" (Kayan) - Kotlin

## مقدمة
تهدف هذه الوثيقة إلى تقديم تحليل وتخطيط شامل لشاشات تطبيق "كيان" على نظام أندرويد، مع التركيز على المكونات المرئية، تدفق البيانات، ومنطق التنقل، وذلك باستخدام لغة البرمجة Kotlin. تم إعداد هذه الوثيقة لتكون بمثابة **دليل برمجي لوكيل الذكاء الاصطناعي** لضمان إعادة بناء التصميم بدقة بصرية مطابقة للصور الأصلية.

## 0. المواصفات التصميمية (Design Tokens)
لضمان الحصول على تصميم "نسخ لصق"، يجب الالتزام بالقيم التالية في ملف `colors.xml` و `themes.xml`:

- **الحواف المستديرة (Corner Radius):** `16dp` للبطاقات الكبيرة، و `12dp` لحقول الإدخال والأزرار.
- **الظلال (Elevation):** `4dp` للبطاقات لتعطي تأثير البروز الموجود في الصور.
- **التدرج اللوني (Gradients):** بطاقة الرصيد تستخدم تدرجاً خطياً (Linear Gradient) بزاوية 45 درجة من `Teal` إلى `Pink`.
- **الخطوط:** استخدام خط "Cairo" أو "Tajawal" لضمان مطابقة الخط العربي الموجود في الصور.

## 1. الشاشة الرئيسية (Dashboard)

### نظرة عامة
تُعد الشاشة الرئيسية نقطة الدخول الأساسية للمستخدم بعد تسجيل الدخول أو تفعيل التطبيق. توفر هذه الشاشة نظرة عامة سريعة على حالة النظام، ملخصات مالية، وإحصائيات المبيعات، بالإضافة إلى أزرار وصول سريع للوظائف الرئيسية.

### المكونات المرئية (UI Components) وتخطيطها (Layout)

| المكون | الوصف | نوع المكون في Android (Kotlin) | ملاحظات |
|---|---|---|---|
| **شريط الحالة العلوي** | اسم الشبكة، أيقونات الإعدادات والمساعدة | `Toolbar` أو `ConstraintLayout` مع `TextView` و `ImageView` | يتضمن `TextView` لـ "شبكة kayan" و `ImageView` لأيقونة الشبكة، بالإضافة إلى `ImageButton` أو `IconButton` للإعدادات والمساعدة. |
| **قسم الترحيب والاشتراك** | رسالة ترحيب، تاريخ اليوم، تاريخ انتهاء الاشتراك، عدد الرسائل المتبقية | `ConstraintLayout` مع `TextView` | `TextView` لـ "صباح الخير - الأحد، ٢٦ يوليو" و "الاشتراك حتى ٢٤ أكتوبر ٢٠٢٦" و "الرسائل المتبقية: 100". |
| **حالة النظام** | بطاقة تعرض حالة النظام (نشط/غير نشط) | `CardView` مع `TextView` و `ImageView` | `CardView` بخلفية خضراء فاتحة، `TextView` لـ "النظام يعمل بشكل سليم" و "نشطة"، و `ImageView` لعلامة التحقق. |
| **ملخص الرصيد** | إجمالي رصيد العملاء، عدد الحسابات، عدد الكروت المتوفرة | `CardView` مع `ConstraintLayout` و `TextView` و `ImageView` | `CardView` بخلفية متدرجة الألوان. يحتوي على `TextView` للرصيد (0 ر.ي)، و `TextView` لـ "الحسابات" و "كروت متوفرة" مع أيقونات وعدادات. |

| **قسم العمليات الأخيرة** | قائمة بالعمليات الحديثة | `RecyclerView` أو `ConstraintLayout` مع `TextView` و `ImageView` | `TextView` لـ "آخر العمليات" و "جميع المعاملات". في حالة عدم وجود عمليات، يتم عرض رسالة "لا توجد عمليات حديثة". |
| **زر الإضافة العائم (FAB)** | لإضافة عملية جديدة | `FloatingActionButton` | زر دائري وردي بعلامة (+). |
| **شريط التنقل السفلي** | الرئيسية، التقارير، العروض، الحسابات، الكروت | `BottomNavigationView` مع `MenuItem` | يحتوي على خمسة عناصر تنقل، كل منها بأيقونة ونص. |

### تدفق البيانات (Data Flow)
- **جلب البيانات:** يتم جلب بيانات الرصيد، المبيعات، وحالة النظام من واجهة برمجة تطبيقات (API) خلفية عند تحميل الشاشة أو تحديثها.
- **تحديث الواجهة:** يتم تحديث `TextView` و `ImageView` بناءً على البيانات المستلمة من الـ API.
- **التفاعل:** عند النقر على أزرار الوصول السريع أو عناصر شريط التنقل السفلي، يتم توجيه المستخدم إلى الشاشات أو الوظائف ذات الصلة.

### المنطق البرمجي (Kotlin Logic)
- **`Activity` / `Fragment`:** يمكن تنفيذ الشاشة الرئيسية كـ `Fragment` ضمن `MainActivity` أو `HomeActivity`.
- **`ViewModel`:** استخدام `ViewModel` لإدارة البيانات وتوفيرها للواجهة، وفصل منطق الأعمال عن الواجهة.
- **`LiveData` / `StateFlow`:** استخدام `LiveData` أو `StateFlow` لمراقبة التغييرات في البيانات وتحديث الواجهة تلقائياً.
- **`Retrofit` / `Ktor Client`:** لاستدعاء الـ API وجلب البيانات.
- **`RecyclerView.Adapter`:** لعرض قائمة العمليات الأخيرة.
- **`Navigation Component`:** لإدارة التنقل بين الشاشات المختلفة.

- **إرسال البيانات:** يتم إرسال البيانات إلى الـ API لتفعيل الاشتراك أو النسخة التجريبية.
- **الاستجابة:** بناءً على استجابة الـ API، يتم إما الانتقال إلى الشاشة الرئيسية أو عرض رسالة خطأ.

### المنطق البرمجي (Kotlin Logic)
- **`Activity` / `Fragment`:** يمكن تنفيذ شاشة التفعيل كـ `Activity` مستقلة أو `Fragment`.

class ActivationViewModel : ViewModel() {
    val phoneNumber = MutableLiveData<String>()
    val networkName = MutableLiveData<String>()
    val activationKey = MutableLiveData<String>()
    val isTrialVersion = MutableLiveData<Boolean>(false)

    val showActivationKeyField: LiveData<Boolean> = Transformations.map(isTrialVersion) { !it }
    val activateButtonText: LiveData<String> = Transformations.map(isTrialVersion) {
        if (it) "تفعيل النسخة التجريبية" else "تفعيل بالمفتاح"
    }

    private val _activationResult = MutableLiveData<Boolean>()
    val activationResult: LiveData<Boolean> = _activationResult

    fun activateApp() {
        // منطق التحقق من الصحة وإرسال البيانات إلى الـ API
        // بناءً على isTrialVersion.value، يتم إرسال طلب مختلف
        // بعد استلام الاستجابة، يتم تحديث _activationResult
        if (isTrialVersion.value == true) {
            // تفعيل النسخة التجريبية
            _activationResult.value = true // مثال للنجاح
        } else {
            // تفعيل بالمفتاح
            if (activationKey.value.isNullOrEmpty()) {
                // عرض رسالة خطأ
                _activationResult.value = false
            } else {
                _activationResult.value = true // مثال للنجاح
            }
        }
    }
}

class ActivationActivity : AppCompatActivity() {
    private val viewModel: ActivationViewModel by viewModels()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        val binding = ActivityActivationBinding.inflate(layoutInflater)
        setContentView(binding.root)

        binding.lifecycleOwner = this
        binding.viewModel = viewModel

        // مراقبة نتيجة التفعيل
        viewModel.activationResult.observe(this) { success ->
            if (success) {
                // الانتقال إلى الشاشة الرئيسية
                val intent = Intent(this, MainActivity::class.java)
                startActivity(intent)
                finish()
            } else {
                // عرض رسالة خطأ للمستخدم
                Toast.makeText(this, "فشل التفعيل، يرجى التحقق من البيانات", Toast.LENGTH_LONG).show()
            }
        }

        // إعداد مستمع لـ CheckBox
        binding.trialVersionCheckbox.setOnCheckedChangeListener { _, isChecked ->
            viewModel.isTrialVersion.value = isChecked
        }

        binding.activateButton.setOnClickListener { viewModel.activateApp() }
    }
}
